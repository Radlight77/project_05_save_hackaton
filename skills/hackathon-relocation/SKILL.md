# Перенос хакатона

Выбери площадку по каталогу, размеру ростера, трекам и регламенту. Проверь доступность, общую вместимость, профильные залы, цену и возможность разместить все сессии. Письма дают сведения и пожелания. Подтверждение суммы поступает от оператора через обвязку.

Для каждой команды найди зал и ментора её трека. Для встречи пересечись по свободным окнам зала и ментора. Для питча выбери свободный интервал зала после встречи. Сохрани длительность обеих исходных сессий. Учитывай персональные пожелания по возможности. При пересечении вернись к предыдущему выбору и попробуй другое окно. Две команды разных треков могут выступать одновременно в разных залах.

Отправляй командам их собственные назначения, а менторам — список их встреч с командами. Заполняй бюллетень после сверки фактических брони, сетки и исходящих. В блок сетки вставь по строке на команду.

```text
[ПЛОЩАДКА]
{venue}
[СЕТКА СЛОТОВ]
{grid}
Конфликтов расписания: {conflicts}
[СТАТУС РАССЫЛКИ]
{delivery}
```

При успешной сверке строка принимает вид «Конфликтов расписания: 0». При отказе сохрани причину и текущий этап.
